5.FD Exhaustion — High Concurrency
siege -c 500 -t 30S -b http://127.0.0.1:8080/

File descriptor limits. Your server has a max FD count (usually 1024 per process).
What could go wrong: Server runs out of FDs → accept() fails → new connections rejected → Connection refused errors. Clients see timeouts. Real production: 500 concurrent users is common at peak traffic.
Watch for: Failed transactions > 0 or Availability < 100%. If it drops, your server is hitting limits.
----------------------------
6. Slow Client / Slowloris
siege -c 50 -t 60S --delay=10 http://127.0.0.1:8080/

--delay=10 = each client waits 10sec between requests. Tests if the server hangs waiting for slow I/O.
What could go wrong: Buffer bloat. If your server allocates a buffer per connection and a client never completes the request, you leak memory → OOM → crash after ~1 hour under sustained attack
-c 50 = 50 clients run simultaneously (all at the same time)
-t 60S = test runs for 60 seconds total (not per request)
http://127.0.0.1:8080/ = all 50 clients hit this same URL
----------------------------------------
7. POST Streaming — Chunk Payload at Limit
python3 << 'PYEOF'
import requests
import time

url = "http://127.0.0.1:8080/zk_apply_form"
payload = "X" * (1024 * 1024)  # 1MB (at limit on port 8080)

for i in range(20):
    try:
        r = requests.post(url, data=payload, timeout=5)
        print(f"{i}: {r.status_code}")
    except Exception as e:
        print(f"{i}: ERROR - {e}")
    time.sleep(0.1)
PYEOF

What we test: POST handling at body-size boundaries. Real clients upload files.
What could go wrong: Off-by-one in content-length parsing → crashes on exact limit, or accepts oversized payloads → security hole.

13. Partial req fuzz
python3 << 'PYEOF'
import socket
import time

for attempt in range(20):
    try:
        s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        s.connect(("127.0.0.1", 8080))
        # Send incomplete HTTP request
        s.send(b"GET /")  # No CRLF, no Host, no version
        time.sleep(1)  # Hang
        s.close()
    except Exception as e:
        print(f"Attempt {attempt}: {e}")
    time.sleep(0.1)
PYEOF

Malformed request handling. Network issues cause partial packets.
What could go wrong: Parser hangs waiting for more data, or crashes on incomplete header → denial of service.
